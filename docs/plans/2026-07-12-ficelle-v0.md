# Ficelle v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic policy server that serves ANY LeRobot checkpoint (diffusion, pi0fast, …) over websockets + msgpack to a dependency-light numpy client, with a self-describing metadata contract and one-line actionable errors.

**Architecture:** Three small server-side files at repo root (`serve.py` websocket transport + CLI, `policy_host.py` all lerobot-touching code, `errors.py`), plus a pip-installable `client/` package (`ficelle-client`: no torch, no lerobot) with a vendored msgpack-numpy codec. Protocol copied from openpi: server pushes a metadata frame on connect, then request/reply msgpack frames; a TEXT frame from the server is always a one-line error. Preprocessing runs server-side through the checkpoint's own serialized processor pipeline (train/inference parity).

**Tech Stack:** Python 3.12 (server) / ≥3.10 (client), uv, lerobot @ pinned upstream commit, websockets ≥14, msgpack, numpy, pytest.

## Decisions log (settled during research — don't relitigate without new facts)

1. **`n_obs_steps > 1` (diffusion=2): the CLIENT sends the frames**, stacked on a leading axis, oldest first. Rationale: the pair must be temporally adjacent frames (~camera period, approximating the 20 ms training spacing — see Grabette `evaluate.py` `run_episode_async`); a server that stacked the current obs with the previous *request's* obs would produce a ~0.5–1 s pair — wrong dynamics, silently degraded policy. Only the client has properly spaced frames.
2. **Server inference path: `policy.reset()` + `predict_action_chunk()` per request — stateless.** At the pinned revision, diffusion's `predict_action_chunk` has a documented **offline mode** (queues empty → uses the batch directly, builds `OBS_IMAGES` itself, accepts `(B, n_obs_steps, …)` time-stacked tensors; `modeling_diffusion.py:102-121`). pi0fast's `predict_action_chunk` is observation-stateless by design. A parity test (Task 7) proves the offline path equals lerobot's own `select_action` queue path with fixed noise.
3. **Metadata is pushed by the server as the first frame after connect** (openpi's exact pattern) — not request-based. The client reads it in its constructor.
4. **Validation errors keep the connection open** (client fixes and retries without reconnect cost); internal errors send the error text then close (openpi behavior).
5. **Requests are serialized** with a `threading.Lock` in `PolicyHost.infer` — one warm model, one robot; concurrent connections are allowed but their requests queue.
6. **pi0fast `empty_camera_*` slots are zero-filled server-side** and excluded from the client contract (uint8 zeros → 0.0 in [0,1] → −1 after SigLIP rescale = training's padding value).
7. Diffusion checkpoints with `n_obs_steps == 1` would hit an upstream shape assert in offline mode — out of scope for v0 (our checkpoints: diffusion n_obs=2, pi0fast n_obs=1). Documented in code.

## Wire protocol (`ficelle/1`)

On connect, server sends one msgpack frame — the metadata:

```python
{
  "protocol": "ficelle/1",
  "checkpoint": "SteveNguyen/test_pick_mustard_200_diffusion-best",
  "policy_type": "diffusion",             # lerobot config.type
  "device": "cuda",
  "n_obs_steps": 2,
  "n_action_steps": 8,                    # actions returned per request
  "chunk_size": 8,                        # model-native chunk (informational)
  "action_dim": 11,
  "fps": 30.0,                            # training dataset fps, or None (best-effort)
  "observations": {                       # excludes empty_camera_* slots
    "observation.images.cam0": {"kind": "image", "dtype": "uint8",
                                 "frame_shape": [96, 96, 3],      # per frame, HWC
                                 "wire_shape": [2, 96, 96, 3]},   # what the client sends
    "observation.state":       {"kind": "state", "dtype": "float32",
                                 "frame_shape": [2], "wire_shape": [2, 2]},
  },
}
```

When `n_obs_steps == 1`, `wire_shape == frame_shape`. Client request: a dict of numpy arrays matching every `observations` entry's `wire_shape`/`dtype` exactly (frames stacked oldest-first when `n_obs_steps > 1`), plus optional `"task": str` (default `""`). Server reply: `{"actions": float32 (n_action_steps, action_dim), "server_timing": {"infer_ms": float, "total_ms": float}}`. Text frame = error, prefixed `ficelle: `.

```python
import asyncio
import socket
import threading
import time

import numpy as np
import pytest

from errors import ObservationError


class FakeHost:
    """Stands in for policy_host.PolicyHost in transport/client tests:
    no lerobot, no checkpoint, instant answers."""

    metadata = {
        "protocol": "ficelle/1",
        "checkpoint": "fake/checkpoint",
        "policy_type": "fake",
        "device": "cpu",
        "n_obs_steps": 1,
        "n_action_steps": 10,
        "chunk_size": 10,
        "action_dim": 2,
        "fps": 30.0,
        "observations": {
            "observation.images.cam0": {"kind": "image", "dtype": "uint8",
                                        "frame_shape": [96, 96, 3], "wire_shape": [96, 96, 3]},
            "observation.state": {"kind": "state", "dtype": "float32",
                                  "frame_shape": [2], "wire_shape": [2]},
        },
    }

    def infer(self, obs):
        expected = set(self.metadata["observations"])
        unknown = {k for k in obs if k.startswith("observation.")} - expected
        if unknown:
            raise ObservationError(
                f"unknown observation key(s) {sorted(unknown)} — expected {sorted(expected)}"
            )
        if obs.get("task") == "reject me":       # hook for server-side-error tests
            raise ObservationError("task 'reject me' rejected as requested")
        if obs.get("task") == "crash":           # hook for internal-error tests
            raise RuntimeError("fake internal crash")
        return {"actions": np.zeros((10, 2), dtype=np.float32)}


def free_port() -> int:
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        return s.getsockname()[1]


class ServerThread:
    """Runs a FicelleServer in a daemon thread. .stop() shuts it down cleanly
    so tests can restart a server on the same port (restart-resilience tests)."""

    def __init__(self, host_obj, port: int | None = None, api_key: str | None = None):
        from serve import FicelleServer

        self.port = port if port is not None else free_port()
        self._server = FicelleServer(host_obj, "127.0.0.1", self.port, api_key=api_key)
        self._loop = asyncio.new_event_loop()
        self._stop_event: asyncio.Event | None = None
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._thread.start()
        self._wait_listening()

    def _run(self):
        asyncio.set_event_loop(self._loop)
        self._loop.run_until_complete(self._main())

    async def _main(self):
        self._stop_event = asyncio.Event()
        server_task = asyncio.ensure_future(self._server.run())
        stop_task = asyncio.ensure_future(self._stop_event.wait())
        await asyncio.wait([server_task, stop_task], return_when=asyncio.FIRST_COMPLETED)
        server_task.cancel()
        try:
            await server_task
        except asyncio.CancelledError:
            pass

    def _wait_listening(self, timeout: float = 10.0):
        deadline = time.monotonic() + timeout
        while time.monotonic() < deadline:
            try:
                with socket.create_connection(("127.0.0.1", self.port), timeout=0.2):
                    return
            except OSError:
                time.sleep(0.05)
        raise RuntimeError(f"server did not start listening on port {self.port}")

    def stop(self):
        while self._stop_event is None:
            time.sleep(0.01)
        self._loop.call_soon_threadsafe(self._stop_event.set)
        self._thread.join(timeout=5)


@pytest.fixture
def fake_host():
    return FakeHost()


@pytest.fixture
def server(fake_host):
    st = ServerThread(fake_host)
    yield st
    st.stop()
```

```python
"""ficelle: serve any LeRobot policy checkpoint over websockets.

Protocol ("ficelle/1", openpi-style — see README):
- on connect the server sends one msgpack frame: the metadata dict
- then request/reply: client sends a msgpack observation dict, server replies
  one msgpack frame {"actions": ..., "server_timing": {...}}
- a TEXT frame from the server is always a one-line error message; validation
  errors keep the connection open, internal errors close it
"""

import asyncio
import http
import logging
import time
import traceback

import websockets.asyncio.server
import websockets.frames

from errors import ObservationError
from ficelle_client import msgpack_numpy

logger = logging.getLogger("ficelle")


class FicelleServer:
    """Websocket transport around a policy host: any object with
    .metadata (dict) and .infer(obs dict) -> reply dict (raising
    ObservationError on bad client input)."""

    def __init__(self, host_obj, host: str, port: int, api_key: str | None = None):
        self._policy_host = host_obj
        self._host = host
        self._port = port
        self._api_key = api_key

    def serve_forever(self) -> None:
        asyncio.run(self.run())

    async def run(self) -> None:
        async with websockets.asyncio.server.serve(
            self._handler,
            self._host,
            self._port,
            compression=None,
            max_size=None,
            process_request=self._process_request,
        ) as server:
            logger.info(f"serving on ws://{self._host}:{self._port}")
            await server.serve_forever()

    def _process_request(self, connection, request):
        if request.path == "/healthz":
            return connection.respond(http.HTTPStatus.OK, "OK\n")
        if self._api_key is not None and request.headers.get("Authorization") != f"Api-Key {self._api_key}":
            return connection.respond(http.HTTPStatus.FORBIDDEN, "ficelle: invalid or missing api key\n")
        return None

    async def _handler(self, websocket):
        logger.info(f"connection from {websocket.remote_address} opened")
        packer = msgpack_numpy.Packer()
        await websocket.send(packer.pack(self._policy_host.metadata))
        while True:
            try:
                request = await websocket.recv()
            except websockets.exceptions.ConnectionClosed:
                logger.info(f"connection from {websocket.remote_address} closed")
                return
            start = time.monotonic()
            try:
                obs = msgpack_numpy.unpackb(request)
                if not isinstance(obs, dict):
                    raise ObservationError("request must be a msgpack-encoded observation dict")
                # inference runs in a thread so websocket keepalive pings keep
                # flowing during a long (0.5 s pi0fast) forward pass
                result = await asyncio.to_thread(self._policy_host.infer, obs)
            except ObservationError as e:
                await websocket.send(f"ficelle: {e}")
                continue
            except Exception:
                logger.error(traceback.format_exc())
                await websocket.send("ficelle: internal server error — see server log for the traceback")
                await websocket.close(
                    code=websockets.frames.CloseCode.INTERNAL_ERROR, reason="internal error"
                )
                return
            result.setdefault("server_timing", {})["total_ms"] = (time.monotonic() - start) * 1000.0
            await websocket.send(packer.pack(result))
```

```python
"""Client for a ficelle policy server.

Deliberately dependency-light (websockets + msgpack + numpy) so it can run in
any robot-side eval loop without torch or lerobot. Validates observations
against the server's metadata BEFORE sending, so mistakes fail fast with a
message naming the offending key.
"""

import logging
import time

import numpy as np
import websockets.exceptions
import websockets.sync.client

from ficelle_client import msgpack_numpy

logger = logging.getLogger("ficelle.client")


class PolicyServerError(RuntimeError):
    """The server replied with an error (text frame)."""


class PolicyClient:
    """Connects to a ficelle server, reads its metadata, then serves
    .infer(obs) -> {"actions": (n_action_steps, action_dim) float32, "server_timing": {...}}.

    Blocks retrying until the server is reachable (like openpi's client) and
    transparently reconnects once if the server restarted between requests.
    """

    def __init__(self, host: str, port: int | None = 8000, api_key: str | None = None,
                 connect_retry_s: float = 5.0):
        self._uri = host if host.startswith("ws") else f"ws://{host}"
        if port is not None and ":" not in self._uri.split("//", 1)[-1]:
            self._uri += f":{port}"
        self._api_key = api_key
        self._connect_retry_s = connect_retry_s
        self._packer = msgpack_numpy.Packer()
        self._ws, self.metadata = self._connect()

    def _connect(self):
        headers = {"Authorization": f"Api-Key {self._api_key}"} if self._api_key else None
        while True:
            try:
                ws = websockets.sync.client.connect(
                    self._uri, compression=None, max_size=None, additional_headers=headers
                )
                metadata = msgpack_numpy.unpackb(ws.recv())
                logger.info(
                    f"connected to {self._uri}: {metadata.get('policy_type')} "
                    f"from {metadata.get('checkpoint')}"
                )
                return ws, metadata
            except websockets.exceptions.InvalidStatus as e:
                if e.response.status_code == 403:
                    raise PolicyServerError(
                        f"server at {self._uri} rejected the api key — check --api_key on both sides"
                    ) from None
                raise
            except ConnectionRefusedError:
                logger.info(f"waiting for server at {self._uri} "
                            f"(retrying every {self._connect_retry_s:.0f}s)...")
                time.sleep(self._connect_retry_s)

    def infer(self, obs: dict) -> dict:
        """One observation dict in, one action chunk out. See server metadata
        (self.metadata['observations']) for the expected keys/shapes/dtypes."""
        self._validate(obs)
        payload = self._packer.pack(obs)
        try:
            self._ws.send(payload)
            response = self._ws.recv()
        except (websockets.exceptions.ConnectionClosed, OSError):
            logger.warning("connection to policy server lost; reconnecting...")
            self._ws, self.metadata = self._connect()
            self._ws.send(payload)
            response = self._ws.recv()
        if isinstance(response, str):
            raise PolicyServerError(response)
        return msgpack_numpy.unpackb(response)

    def _validate(self, obs: dict) -> None:
        spec = self.metadata["observations"]
        n_obs = self.metadata.get("n_obs_steps", 1)
        if "task" in obs and not isinstance(obs["task"], str):
            raise ValueError(f"'task' must be a string, got {type(obs['task']).__name__}")
        for key in obs:
            if key != "task" and key not in spec:
                raise ValueError(
                    f"unknown observation key '{key}' — the server expects {sorted(spec)}"
                )
        for key, s in spec.items():
            if key not in obs:
                raise ValueError(
                    f"missing observation key '{key}' — the server expects {sorted(spec)}"
                )
            arr = obs[key]
            if not isinstance(arr, np.ndarray):
                raise ValueError(f"'{key}' must be a numpy array, got {type(arr).__name__}")
            if list(arr.shape) != list(s["wire_shape"]):
                hint = f" ({n_obs} frames stacked oldest-first)" if n_obs > 1 else ""
                raise ValueError(
                    f"'{key}' has shape {list(arr.shape)}, expected {list(s['wire_shape'])}{hint}"
                )
            if str(arr.dtype) != s["dtype"]:
                raise ValueError(f"'{key}' has dtype {arr.dtype}, expected {s['dtype']}")

    def close(self) -> None:
        self._ws.close()

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.close()
```

```python
"""Everything that touches lerobot: checkpoint loading, the metadata contract,
and turning raw numpy observations into action chunks.

Preprocessing runs HERE, through the checkpoint's own serialized processor
pipeline — the server is the only place that can guarantee train/inference
processing parity (see docs/policy_server_project_brief.md §2.3).
"""

import json
import logging
import threading
import time
from pathlib import Path

import numpy as np
import torch
from huggingface_hub import hf_hub_download
from lerobot.configs.policies import PreTrainedConfig
from lerobot.configs.types import FeatureType
from lerobot.policies.factory import get_policy_class, make_pre_post_processors
from lerobot.policies.utils import prepare_observation_for_inference
from lerobot.utils.constants import ACTION

from errors import ObservationError

logger = logging.getLogger("ficelle.policy")

PROTOCOL = "ficelle/1"


def load_policy_host(checkpoint: str, device: str, dtype: str | None) -> "PolicyHost":
    """Load ANY LeRobot policy checkpoint (hub repo id or local dir) for serving.

    CPU-first load, optional dtype cast, then move to device — the memory-tight
    pattern proven on the 3B pi0fast (Grabette's smoke_generation.py).
    """
    cfg = PreTrainedConfig.from_pretrained(checkpoint)
    cfg.device = "cpu"
    policy = get_policy_class(cfg.type).from_pretrained(checkpoint, config=cfg)
    if dtype is not None:
        policy = policy.to(dtype=getattr(torch, dtype))
    policy.eval()
    policy = policy.to(device)
    policy.config.device = device
    preprocessor, postprocessor = make_pre_post_processors(
        policy.config,
        pretrained_path=checkpoint,
        preprocessor_overrides={"device_processor": {"device": device}},
    )
    return PolicyHost(policy, preprocessor, postprocessor, checkpoint=checkpoint,
                      device=device, fps=read_training_fps(checkpoint))


def read_training_fps(checkpoint: str) -> float | None:
    """Best-effort: fps is not in the policy config — it lives in the training
    dataset's info.json, reachable via the checkpoint's train_config.json."""
    try:
        ckpt_dir = Path(checkpoint)
        if ckpt_dir.is_dir():
            train_cfg = json.loads((ckpt_dir / "train_config.json").read_text())
        else:
            train_cfg = json.loads(Path(hf_hub_download(checkpoint, "train_config.json")).read_text())
        repo_id = train_cfg["dataset"]["repo_id"]
        info_path = hf_hub_download(repo_id, "meta/info.json", repo_type="dataset")
        return float(json.loads(Path(info_path).read_text())["fps"])
    except Exception as e:  # noqa: BLE001 — metadata nicety, never fatal
        logger.warning(f"could not determine training fps ({e}); metadata will report fps=None")
        return None


class PolicyHost:
    """Wraps a loaded policy + processor pipelines behind the two-member
    contract the websocket transport needs: .metadata and .infer().

    Each request is STATELESS: reset() + predict_action_chunk(). For
    n_obs_steps > 1 the client sends the frame history itself (temporally
    adjacent frames — see docs/plans/2026-07-12-ficelle-v0.md decision 1) and
    we feed diffusion's offline mode with a time-stacked batch.

    Known limit: a diffusion checkpoint with n_obs_steps == 1 would trip an
    upstream shape assert in offline mode (state would need a time axis);
    no such checkpoint is in scope for v0.
    """

    def __init__(self, policy, preprocessor, postprocessor, checkpoint: str,
                 device: str, fps: float | None):
        self._policy = policy
        self._pre = preprocessor
        self._post = postprocessor
        self._device = device
        # one warm model, requests serialized: reset()+predict must not interleave
        self._lock = threading.Lock()
        cfg = policy.config
        self._n_obs_steps = int(getattr(cfg, "n_obs_steps", 1))
        self._n_action_steps = int(cfg.n_action_steps)
        # pi0fast injects zero-filled empty_camera_* slots into input_features;
        # they are our job, not the client's (uint8 zeros -> -1 after SigLIP
        # rescale = training's padding value)
        self._empty_camera_keys = [k for k in cfg.input_features if "empty_camera" in k]
        self._obs_spec = self._build_obs_spec(cfg)
        self.metadata = {
            "protocol": PROTOCOL,
            "checkpoint": checkpoint,
            "policy_type": cfg.type,
            "device": device,
            "n_obs_steps": self._n_obs_steps,
            "n_action_steps": self._n_action_steps,
            "chunk_size": int(getattr(cfg, "chunk_size", 0)) or self._n_action_steps,
            "action_dim": int(cfg.output_features[ACTION].shape[0]),
            "fps": fps,
            "observations": self._obs_spec,
        }

    def _build_obs_spec(self, cfg) -> dict:
        """The client-facing contract: images as uint8 HWC, states as float32."""
        spec = {}
        for name, feat in cfg.input_features.items():
            if name in self._empty_camera_keys:
                continue
            if feat.type is FeatureType.VISUAL:
                c, h, w = feat.shape
                spec[name] = {"kind": "image", "dtype": "uint8", "frame_shape": [h, w, c]}
            else:
                spec[name] = {"kind": "state", "dtype": "float32", "frame_shape": list(feat.shape)}
        for s in spec.values():
            s["wire_shape"] = ([self._n_obs_steps] + s["frame_shape"]
                               if self._n_obs_steps > 1 else list(s["frame_shape"]))
        return spec

    def infer(self, obs: dict) -> dict:
        self._validate(obs)
        task = obs.get("task", "")
        frames = self._split_frames(obs)
        with self._lock:
            processed = []
            for frame in frames:
                # lerobot's own helper: uint8 HWC -> float32 CHW in [0,1],
                # add batch dim, move to device, attach task
                prepared = prepare_observation_for_inference(
                    frame, torch.device(self._device), task=task
                )
                processed.append(self._pre(prepared))
            if self._n_obs_steps == 1:
                batch = processed[0]
            else:
                # time-stack per-frame preprocessed tensors to (B, n_obs_steps, ...)
                # for predict_action_chunk's offline mode (queues empty after reset)
                batch = dict(processed[-1])
                for key in self._obs_spec:
                    batch[key] = torch.stack([p[key] for p in processed], dim=1)
            t0 = time.perf_counter()
            with torch.no_grad():
                self._policy.reset()
                actions = self._policy.predict_action_chunk(batch)
            infer_ms = (time.perf_counter() - t0) * 1000.0
            if actions.ndim != 3:
                actions = actions.unsqueeze(0)
            # postprocessor (unnormalize -> cpu) expects (B, action_dim): per step
            steps = [self._post(actions[:, i]) for i in range(actions.shape[1])]
        chunk = np.stack([a.squeeze(0).float().cpu().numpy() for a in steps]).astype(np.float32)
        return {"actions": chunk, "server_timing": {"infer_ms": infer_ms}}

    def _split_frames(self, obs: dict) -> list[dict]:
        """n_obs_steps single-frame numpy dicts, oldest first. Copies are
        deliberate: msgpack-decoded arrays are read-only, torch.from_numpy needs
        writable memory. Empty camera slots are zero-filled here."""
        frames = [{} for _ in range(self._n_obs_steps)]
        for key in self._obs_spec:
            arr = obs[key]
            for i, frame in enumerate(frames):
                frame[key] = np.array(arr[i] if self._n_obs_steps > 1 else arr)
        for key in self._empty_camera_keys:
            c, h, w = self._policy.config.input_features[key].shape
            for frame in frames:
                frame[key] = np.zeros((h, w, c), dtype=np.uint8)
        return frames

    def _validate(self, obs: dict) -> None:
        spec = self._obs_spec
        if "task" in obs and not isinstance(obs["task"], str):
            raise ObservationError(f"'task' must be a string, got {type(obs['task']).__name__}")
        for key in obs:
            if key != "task" and key not in spec:
                raise ObservationError(
                    f"unknown observation key '{key}' — expected {sorted(spec)} (+ optional 'task')"
                )
        for key, s in spec.items():
            if key not in obs:
                raise ObservationError(
                    f"missing observation key '{key}' — expected {sorted(spec)} (+ optional 'task')"
                )
            arr = obs[key]
            if not isinstance(arr, np.ndarray):
                raise ObservationError(f"'{key}' must be a numpy array, got {type(arr).__name__}")
            if list(arr.shape) != s["wire_shape"]:
                hint = (f" ({self._n_obs_steps} frames stacked oldest-first)"
                        if self._n_obs_steps > 1 else "")
                raise ObservationError(
                    f"'{key}' has shape {list(arr.shape)}, expected {s['wire_shape']}{hint}"
                )
            if str(arr.dtype) != s["dtype"]:
                raise ObservationError(f"'{key}' has dtype {arr.dtype}, expected {s['dtype']}")
```

```python
"""Synthetic-observation latency probe for a ficelle server.

Reads the server's metadata, sends N random observations that match it, and
prints round-trip latency percentiles. Needs only ficelle-client + numpy —
run it from any machine that can reach the server (e.g. over Tailscale):

    uv run python examples/random_client.py --host 100.x.y.z [-n 50] [--task "pick up the cup"]
"""

import argparse
import logging
import time

import numpy as np

from ficelle_client import PolicyClient


def synthetic_obs(metadata: dict, task: str, rng: np.random.Generator) -> dict:
    obs = {"task": task}
    for key, spec in metadata["observations"].items():
        if spec["dtype"] == "uint8":
            obs[key] = rng.integers(0, 256, size=spec["wire_shape"], dtype=np.uint8)
        else:
            obs[key] = rng.standard_normal(spec["wire_shape"]).astype(np.float32)
    return obs


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__,
                                     formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--host", required=True)
    parser.add_argument("--port", type=int, default=8000)
    parser.add_argument("--api_key", default=None)
    parser.add_argument("-n", type=int, default=50, help="number of timed requests")
    parser.add_argument("--task", default="", help="task string to send (for VLA policies)")
    args = parser.parse_args()

    logging.basicConfig(level=logging.INFO)
    rng = np.random.default_rng(0)
    with PolicyClient(args.host, args.port, api_key=args.api_key) as client:
        meta = client.metadata
        print(f"policy {meta['policy_type']} from {meta['checkpoint']} on {meta['device']} | "
              f"{meta['n_action_steps']} x {meta['action_dim']} actions per request | "
              f"n_obs_steps {meta['n_obs_steps']} | training fps {meta['fps']}")

        # warmup request: first inference pays cuda/tokenizer warmup, don't time it
        reply = client.infer(synthetic_obs(meta, args.task, rng))
        expected_shape = (meta["n_action_steps"], meta["action_dim"])
        assert reply["actions"].shape == expected_shape, reply["actions"].shape

        rtt, infer = [], []
        for i in range(args.n):
            t0 = time.perf_counter()
            reply = client.infer(synthetic_obs(meta, args.task, rng))
            rtt.append((time.perf_counter() - t0) * 1000.0)
            infer.append(reply["server_timing"]["infer_ms"])
            print(f"req {i:3d} | rtt {rtt[-1]:7.1f} ms | server infer {infer[-1]:7.1f} ms")

        rtt_a, infer_a = np.array(rtt), np.array(infer)
        print(f"\n{args.n} requests | rtt p50 {np.percentile(rtt_a, 50):.1f} ms "
              f"p95 {np.percentile(rtt_a, 95):.1f} ms | "
              f"server infer p50 {np.percentile(infer_a, 50):.1f} ms "
              f"p95 {np.percentile(infer_a, 95):.1f} ms | "
              f"network+serialization p50 {np.percentile(rtt_a - infer_a, 50):.1f} ms")
        print(f"actions shape OK: {expected_shape}")


if __name__ == "__main__":
    main()
```

```python
def test_offline_chunk_matches_select_action_queue_path(diffusion_host):
    """The served path (reset + predict_action_chunk on a time-stacked batch,
    offline mode) must equal lerobot's own select_action queue path — same
    frame pair, same noise. This is the correctness proof for decision 2."""
    from lerobot.policies.utils import prepare_observation_for_inference
    from lerobot.utils.constants import ACTION

    policy = diffusion_host._policy
    pre = diffusion_host._pre
    device = torch.device(diffusion_host._device)
    meta = diffusion_host.metadata
    rng = np.random.default_rng(1)

    obs = _synthetic_obs(meta, rng)
    frames = diffusion_host._split_frames(obs)
    processed = [pre(prepare_observation_for_inference(f, device, task="")) for f in frames]

    action_dim = meta["action_dim"]
    horizon = policy.config.horizon
    noise = torch.randn(1, horizon, action_dim, generator=torch.Generator().manual_seed(0)).to(device)

    # lerobot's own path: two select_action calls (Grabette evaluate.py pattern)
    policy.reset()
    _ = policy.select_action(dict(processed[0]), noise=noise)  # junk chunk from duplicated frame
    policy._queues[ACTION].clear()                             # flush it
    first = policy.select_action(dict(processed[1]), noise=noise)
    rest = [policy._queues[ACTION].popleft() for _ in range(len(policy._queues[ACTION]))]
    queue_chunk = torch.stack([first, *rest], dim=1)           # (1, n_action_steps, dim)

    # ficelle's served path: offline mode on a time-stacked batch
    policy.reset()
    stacked = dict(processed[-1])
    for key in meta["observations"]:
        stacked[key] = torch.stack([processed[0][key], processed[1][key]], dim=1)
    offline_chunk = policy.predict_action_chunk(stacked, noise=noise)

    torch.testing.assert_close(offline_chunk, queue_chunk, rtol=1e-4, atol=1e-5)


def test_end_to_end_over_websocket(diffusion_host):

                client.infer(bad)
    finally:
        st.stop()
```
